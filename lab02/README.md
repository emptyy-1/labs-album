# Лабораторная работа №2: Приближённое вычисление функций с помощью рядов Тейлора

**Вариант 2.9:** Разложение функции cos(x)

---

## 1. Постановка задачи
Вычислить значение функции cos(x) через бесконечный ряд Тейлора с точностью $\varepsilon = 10^{-k}$ (где $k$ — натуральное число):
$$\cos(x) = 1 - \frac{x^2}{2!} + \frac{x^4}{4!} - \frac{x^6}{6!} + \dots$$

**Ограничения и требования:**
- Слагаемые накапливаются в сумме, пока $|\text{слагаемое}| \ge \varepsilon$.
- Запрещено вычислять степени и факториалы отдельными функциями.
- Результат сравнивается со стандартным `std::cos(x)` с выводом разности (погрешности).
- Ввод аргументов валидируется циклом `while (true)`.
- Необходимо определить предел аргумента $x$, при котором сохраняется точность.

---

## 2. Подход к решению

### Рекуррентный расчет слагаемых
Для предотвращения переполнения типов данных факториал и степень отдельно не считаются. Очередное слагаемое получается домножением предыдущего на множитель:
$$\text{множитель} = -\frac{x^2}{(n - 1) \cdot n}$$
Счетчик $n$ стартует с $2.0$ и увеличивается на $2.0$ на каждом шаге (тип `double` исключает переполнение счетчика).

### Предел точности по x (Пункт 6)
Математически ряд сходится на всей числовой оси, но из-за ограничений машинной арифметики (`double`) при $|x| > 25$ промежуточные слагаемые $x^n$ становятся огромными. При сложении чисел с плавающей точкой разных порядков происходит потеря точности (машинное округление), и погрешность резко возрастает. 
Предел корректного счета без приведения к периоду $[-\pi; \pi]$ — диапазон $|x| \le 25$.
